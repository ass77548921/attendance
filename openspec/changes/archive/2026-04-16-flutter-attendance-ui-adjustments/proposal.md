## Why

Flutter 前台應用在實際使用中發現多處用戶體驗問題：強制修改密碼頁面缺乏返回機制導致用戶卡住、打卡時間顯示格式不完整、遲到與早退狀態提示不足、補打卡頁面導航缺失、以及導航列轉場動畫異常。這些問題影響日常打卡操作流暢度與系統可用性，需要立即優化以提升用戶滿意度。

## What Changes

- 在強制密碼修改頁面新增登出返回功能，讓用戶可以選擇延後修改密碼
- 調整打卡頁面時間格式為「年-月-日 時:分:秒 時區地點」，提供完整資訊
- 在打卡主頁上班時間顯示遲到標記（若超過規定上班時間）
- 在下班打卡前檢測工作時數，未滿標準工時時顯示早退提示
- 提早打下班時彈出確認對話框，防止誤操作
- 為補打卡詳情頁面新增返回導航（左側 nav 或返回按鈕）
- 修復導航列 item 切換時整頁轉場動畫問題，改為固定導航列僅切換內容區
- 將整體配色調整為藍色主題，優化樣式排版與視覺一致性

## Capabilities

### New Capabilities
- `flutter-ui-theme-system`: 定義 Flutter 應用的整體主題系統，包含色彩方案、排版規範、組件樣式

### Modified Capabilities
- `password-change-flow`: 新增強制修改密碼頁面的登出功能
- `flutter-attendance-ui`: 新增時間格式規範、遲到顯示、早退檢測與確認對話框
- `flutter-amendment-ui`: 新增詳情頁面的返回導航功能
- `flutter-app-foundation`: 修復導航列轉場動畫問題，確保導航固定不參與轉場

## Impact

**前端影響範圍：**
- `lib/features/auth/` - 密碼修改頁面流程與 UI
- `lib/features/attendance/` - 打卡主頁、打卡紀錄頁面的時間顯示與狀態邏輯
- `lib/features/amendment/` - 補打卡詳情頁面的導航結構
- `lib/core/theme/` - 新增或重構主題系統配置
- `lib/core/widgets/` - 導航組件的實現方式（可能需要調整 Scaffold 使用）

**潛在 API 影響：**
- 遲到與早退判定邏輯：需確認 API 回傳資料中是否包含標準上班時間、標準工時等參考值，若無則需要前端配置或 API 新增欄位

**依賴項：**
- 可能需要引入日期時間格式化套件（如 `intl`）來處理時區與地區格式
- 主題系統可能需要 `flutter_riverpod` 狀態管理來實現全域主題切換（如已使用）

**使用者影響：**
- 所有前端使用者將看到新的藍色主題與改進的 UI
- 強制修改密碼的使用者現在可以選擇登出
- 打卡與補打卡操作體驗更流暢
