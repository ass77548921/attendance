## ADDED Requirements

### Requirement: 郵件發送設定管理
系統 SHALL 提供管理員維護郵件發送設定，至少包含 SMTP 主機、連接埠、寄件帳號、寄件密碼、寄件顯示名稱與預設主旨模板。

#### Scenario: 查詢目前郵件設定
- **WHEN** 管理員呼叫郵件設定查詢 API
- **THEN** 系統回傳目前設定值，且敏感欄位（密碼）不得明文回傳

#### Scenario: 更新郵件設定
- **WHEN** 管理員提交完整或部分郵件設定更新
- **THEN** 系統驗證欄位格式後儲存設定，回傳更新結果

### Requirement: 郵件憑證安全儲存
系統 MUST 對寄件密碼採加密或秘密管理機制儲存，並禁止在日誌與 API 回應中暴露明文。

#### Scenario: 儲存新寄件密碼
- **WHEN** 管理員更新寄件密碼
- **THEN** 系統以安全機制儲存密碼，不得以明文持久化

#### Scenario: 查詢設定與稽核日誌
- **WHEN** 管理員查詢設定或系統輸出日誌
- **THEN** 回應與日誌不得包含明文寄件密碼

### Requirement: 測試發送驗證
系統 SHALL 提供測試郵件發送功能，用於驗證當前設定可用性。

#### Scenario: 測試發送成功
- **WHEN** 管理員以目前設定發送測試郵件
- **THEN** 系統回傳成功結果，並記錄測試發送時間與目標收件人

#### Scenario: 測試發送失敗
- **WHEN** SMTP 設定錯誤或連線失敗
- **THEN** 系統回傳錯誤摘要，並記錄失敗原因供排查
