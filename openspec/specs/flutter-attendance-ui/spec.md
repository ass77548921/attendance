## ADDED Requirements

### Requirement: 打卡時間格式完整顯示
系統 SHALL 以「年-月-日 時:分:秒 時區地點」格式顯示所有打卡時間，包含打卡主頁與打卡紀錄列表的上下班時間。時區資訊 SHALL 根據裝置設定自動判定。

#### Scenario: 打卡主頁顯示完整時間格式
- **WHEN** 打卡主頁顯示今日上班或下班時間
- **THEN** 時間顯示為「2026-04-16 09:05:23 GMT+8 台北」或類似格式

#### Scenario: 打卡紀錄列表顯示完整時間
- **WHEN** 顯示歷史打卡紀錄的上班與下班時間
- **THEN** 每筆紀錄的時間欄位皆使用完整格式，包含年月日、時分秒、時區與地點

#### Scenario: 時區地點依裝置設定
- **WHEN** 裝置設定為不同時區（如 GMT+9 東京）
- **THEN** 顯示的時區與地點自動對應裝置設定

---

### Requirement: 打卡主頁遲到標記
系統 SHALL 在打卡主頁顯示上班時間時，若實際打卡時間晚於規定上班時間，顯示「遲到」標記並使用醒目顏色（警告色）提示。

#### Scenario: 準時上班不顯示遲到
- **WHEN** 使用者在規定上班時間或之前打卡
- **THEN** 上班時間正常顯示，不顯示任何遲到標記

#### Scenario: 遲到顯示紅色標記
- **WHEN** 使用者上班打卡時間晚於規定上班時間（如規定 09:00，實際 09:15）
- **THEN** 上班時間旁顯示紅色「遲到」標籤或圖示

#### Scenario: 遲到判定依據 API 回應
- **WHEN** API 回應中包含 `isLate: true` 欄位
- **THEN** 前端依此欄位決定是否顯示遲到標記，不在前端重新計算

---

### Requirement: 早退檢測與提示
系統 SHALL 在使用者進行下班打卡前，檢查目前工作時長是否滿足標準工時。若未滿足，顯示「早退」提示資訊。

#### Scenario: 滿足工時正常打卡
- **WHEN** 使用者點擊下班打卡時，工作時長已達標準工時（如 8 小時）
- **THEN** 直接執行打卡，不顯示任何額外提示

#### Scenario: 未滿工時顯示早退提示
- **WHEN** 使用者點擊下班打卡時，工作時長未達標準工時
- **THEN** 打卡按鈕旁或下方顯示黃色警告文字「提醒：目前工作未滿標準工時，可能視為早退」

#### Scenario: 早退判定依據 API 配置
- **WHEN** 前端需要判斷是否為早退
- **THEN** 使用 API 回傳的標準工時參數（如 `standardWorkHours: 8`）與當前時長比較

---

### Requirement: 提早下班打卡確認對話框
系統 SHALL 在使用者工作時長未滿標準工時時，點擊下班打卡觸發確認對話框，防止誤操作並提醒可能後果。

#### Scenario: 滿足工時直接打卡
- **WHEN** 工作時長已達標準工時，使用者點擊下班打卡
- **THEN** 直接執行打卡 API，不彈出確認對話框

#### Scenario: 未滿工時彈出確認對話框
- **WHEN** 工作時長未達標準工時，使用者點擊下班打卡
- **THEN** 彈出對話框：「您的工作時長未滿標準工時（已工作 X 小時，標準 Y 小時），確定要下班打卡嗎？」，提供「取消」與「確定打卡」按鈕

#### Scenario: 確認打卡執行 API
- **WHEN** 使用者在對話框中點擊「確定打卡」
- **THEN** 執行下班打卡 API，關閉對話框，更新頁面狀態

#### Scenario: 取消打卡停留頁面
- **WHEN** 使用者在對話框中點擊「取消」
- **THEN** 關閉對話框，不執行打卡動作，停留在打卡主頁
